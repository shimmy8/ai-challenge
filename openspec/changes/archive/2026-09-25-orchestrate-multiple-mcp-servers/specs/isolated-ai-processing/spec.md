## Purpose

Предоставляет фоновым и интерактивным pipeline изолированное текстовое преобразование через LLM без доступа к пользовательскому диалогу, памяти или внешним инструментам.

## ADDED Requirements

### Requirement: AI processing is exposed as a bounded MCP tool
Сервер `ai` SHALL предоставлять read-only инструмент `generate_text`, принимающий явные инструкции и JSON-совместимый вход и возвращающий текст вместе с безопасной информацией об использованной модели. Инструмент MUST отклонять пустые инструкции и вход, превышающий установленный предел.

#### Scenario: Structured input is transformed
- **WHEN** инструмент получает допустимые инструкции и структурированный вход
- **THEN** он выполняет один модельный запрос и возвращает непустой текстовый результат

### Requirement: AI processing has isolated context and no tools
Модельный запрос инструмента MUST содержать только фиксированные системные ограничения, переданные инструкции и вход текущего вызова. Он MUST NOT получать интерактивную историю, профиль, долговременную память, активную задачу, MCP-инструменты или право выполнять внешние действия.

#### Scenario: Interactive history contains unrelated private data
- **WHEN** `generate_text` вызывается при наличии сохранённых диалогов и памяти
- **THEN** эти данные отсутствуют в модельном запросе и не могут появиться в результате через контекст приложения

#### Scenario: Provider returns a tool call
- **WHEN** LLM-провайдер возвращает structured tool call вместо текста
- **THEN** AI-сервер не выполняет его и возвращает безопасную ошибку

### Requirement: Provider credentials and failures remain local
Ключи OpenAI или Claude MUST загружаться только локальным AI-сервером и MUST NOT появляться в схеме инструмента, аргументах, результате, trace, stdout или пользовательской ошибке.

#### Scenario: Provider is unavailable
- **WHEN** модельный запрос завершается сетевой ошибкой, тайм-аутом или отказом провайдера
- **THEN** инструмент возвращает безопасную ошибку без учётных данных и без выдуманного результата
