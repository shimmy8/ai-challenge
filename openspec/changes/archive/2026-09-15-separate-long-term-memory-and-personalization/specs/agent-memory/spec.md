## ADDED Requirements

### Requirement: Пользователь явно управляет долговременными фактами
Система SHALL позволять пользователю командой `/remember <текст>` явно сохранить факт в долговременную память, просмотреть сохранённые факты и удалить выбранный факт. Команда `/remember` SHALL изменять только долговременную память и SHALL NOT изменять историю или производный контекст сессии, активную задачу, её TODO либо профиль персонализации. Система SHALL NOT автоматически переносить в долговременную память обычные сообщения, summary, sticky facts, профиль персонализации или данные задачи.

#### Scenario: Сохранение факта
- **WHEN** пользователь выполняет `/remember <текст>`
- **THEN** система сохраняет отдельный долговременный факт и делает его доступным в последующих сессиях

#### Scenario: Сохранение факта не меняет задачу и сессию
- **WHEN** пользователь выполняет `/remember <текст>` при активной задаче и непустой истории
- **THEN** система добавляет только долговременный факт, сохраняя задачу, TODO, фазу и краткосрочный контекст без изменений

#### Scenario: Обычное сообщение не становится долговременной памятью
- **WHEN** пользователь отправляет обычное сообщение без команды сохранения
- **THEN** система оставляет сообщение в краткосрочной памяти и не создаёт долговременный факт

#### Scenario: Удаление записи требует подтверждения
- **WHEN** пользователь выбирает удаление долговременного факта, но не подтверждает действие
- **THEN** система сохраняет факт без изменений

### Requirement: Долговременные факты передаются как данные
Система SHALL добавлять сохранённые долговременные факты к каждому основному запросу как явно маркированные контекстные данные, а не как инструкции модели. Идентификатор каждого факта SHALL оставаться различимым в сформированном контексте.

#### Scenario: Факт доступен в новом диалоге
- **WHEN** пользователь начинает новую сессию после явного сохранения факта
- **THEN** следующий основной запрос содержит этот факт в секции долговременных данных

#### Scenario: Текст записи не становится командой
- **WHEN** долговременный факт содержит повелительную формулировку
- **THEN** системный prompt маркирует факт как данные и не включает его в секцию инструкций персонализации
