## Why

`fox-llm` уже умеет подключаться к MCP-серверу, получать список инструментов и сохранять пользовательский allowlist, но агент ещё не может запросить выполнение инструмента и использовать его результат. Для задания Дня 17 нужен проверяемый end-to-end сценарий с реальным внешним эффектом: пользователь формулирует встречу естественным языком, подтверждает предложенные параметры, после чего событие появляется в его личном Яндекс Календаре.

## What Changes

- В основной цикл агента добавляется structured tool calling: актуальные схемы включённых MCP-инструментов передаются выбранному провайдеру, запрос модели проверяется по allowlist, выполняется через MCP `tools/call`, а результат возвращается модели для итогового ответа.
- Для операций создания календарного события приложение показывает нормализованные параметры и требует отдельного подтверждения пользователя до внешней записи; отменённый вызов не изменяет календарь.
- Локальный демонстрационный MCP-сервер получает инструмент `create_calendar_event` для личного Яндекс Календаря через CalDAV с обязательными названием, временем начала и окончания и необязательными описанием и местом.
- Относительные даты интерпретируются с учётом текущей даты и часового пояса приложения; при отсутствии времени или продолжительности агент обязан запросить уточнение вместо применения скрытых значений по умолчанию.
- Учётные данные CalDAV читаются из переменных окружения и не сохраняются в репозитории или истории диалога.
- Добавляются изолированные тесты с поддельными провайдером, MCP-клиентом и CalDAV endpoint, а также инструкция ручной проверки с личным аккаунтом в `reports/day17/`.

## Capabilities

### New Capabilities

- `mcp-tool-execution`: Передача разрешённых MCP-инструментов OpenAI и Claude, контролируемое выполнение model tool calls и использование результатов в итоговом ответе агента.
- `yandex-calendar-events`: Подтверждаемое создание личного события в Яндекс Календаре через MCP и CalDAV без приглашения участников.

### Modified Capabilities

Нет.

## Impact

- `src/mcp.rs`: полные описания инструментов, MCP `tools/call`, календарный tool handler и CalDAV-клиент.
- `src/providers.rs`, `src/agent.rs` и общие типы модели: provider-specific сериализация и разбор tool calls, ограниченный цикл выполнения и возврат tool results.
- `src/app.rs` и `src/cli.rs`: загрузка MCP runtime, отображение предварительного просмотра и интерактивное подтверждение внешней записи.
- `src/config.rs`: публичные секреты в конфигурацию не добавляются; MCP endpoint и allowlist сохраняют текущий формат.
- `src/tests.rs`: регрессии для обоих провайдеров, allowlist, подтверждения, отмены, лимита циклов, ошибок MCP/CalDAV и относительных дат.
- `README.md` и `reports/day17/`: настройка пароля приложения, переменных окружения и воспроизводимый сценарий демонстрации.
- Внешняя система: личный Яндекс Календарь по стандартному CalDAV endpoint `https://caldav.yandex.ru`; реализация потребует сетевого доступа только при ручном/рабочем вызове.
