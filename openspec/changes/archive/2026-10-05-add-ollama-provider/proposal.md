## Why

`fox-llm` поддерживает только облачные OpenAI и Claude, поэтому для работы агента требуется внешний API-ключ и сетевой доступ. Добавление Ollama позволит запускать совместимую LLM полностью локально, использовать существующий CLI, память и MCP-инструменты и одновременно выполнить практическое задание по локальной LLM на базе самого проекта.

## What Changes

- Добавить Ollama в список выбираемых LLM-провайдеров с локальным endpoint по умолчанию `http://127.0.0.1:11434/v1` и моделью `qwen3.5:4b`.
- Выполнять локальные запросы без API-ключа через совместимый Responses API Ollama и выдавать понятную русскую ошибку, если сервер недоступен или его версия не поддерживает необходимый API.
- Получать список уже установленных локальных моделей и разрешать их выбор через существующий CLI.
- Сохранять выбранный локальный провайдер и модель в конфигурации и сессиях, не ломая загрузку существующих конфигураций и legacy-данных.
- Поддержать для Ollama тот же цикл структурированных MCP tool calls, итогового ответа, памяти, сжатия контекста, метрик и изолированных AI-запросов, который действует для облачных провайдеров.
- Добавить регрессионные тесты конфигурации, сериализации провайдера, построения и разбора запросов, списка моделей, отсутствия авторизации и provider-neutral tool-calling.

## Capabilities

### New Capabilities

- `local-llm-provider`: выбор, конфигурация и использование локальной Ollama-модели через CLI и HTTP API без обязательного API-ключа.

### Modified Capabilities

- `mcp-tool-execution`: Ollama становится поддерживаемым провайдером для передачи определений инструментов, structured tool calls и возврата результатов модели.
- `isolated-ai-processing`: изолированные фоновые LLM-запросы могут выполняться через выбранную локальную Ollama-модель без облачных credentials.

## Impact

- Затрагиваются `src/config.rs`, `src/agent.rs`, `src/providers.rs`, `src/cli.rs`, `src/app.rs`, `src/sessions.rs` и регрессионные тесты в `src/tests.rs`.
- Используется уже существующий `reqwest`; новая runtime-зависимость для клиента Ollama не требуется.
- Для Responses API и function tools потребуется совместимая версия Ollama (не ниже версии, в которой появился `/v1/responses`, — `0.13.3`).
- Внешние OpenAI/Claude API и их конфигурация остаются обратно совместимыми; существующие пользовательские файлы конфигурации должны автоматически получить отсутствующую запись Ollama без потери данных.
