## Why

День 30 требует превратить локальную LLM в приватный сетевой сервис с HTTP API и чатом, а также подтвердить доступ по сети, устойчивость нескольких запросов и базовые ограничения. Raspberry Pi 5 с 8 ГБ и фиксированным адресом в одной подсети позволяет вынести inference с MacBook на отдельное домашнее устройство и сохранить данные внутри локальной сети.

## What Changes

- Развернуть на Raspberry Pi ARM64-сборку Ollama и компактную модель `qwen3:1.7b`, выполняющую inference непосредственно на Pi.
- Предоставить MacBook HTTP API для чата через фиксированный адрес Pi, не публикуя сервис в интернете.
- Поставить перед локальным Ollama ограниченный локальной подсетью HTTP gateway с rate limit и оставить backend Ollama недоступным напрямую по сети.
- Зафиксировать максимальный контекст 4096 токенов и предсказуемое отклонение запросов, нарушающих ограничения gateway или модели.
- Добавить в `fox-llm` отдельного провайдера `Ollama Remote` с настраиваемым HTTP(S) endpoint и моделью `qwen3:1.7b` по умолчанию, не меняя существующий локальный провайдер `Ollama` и его endpoint `http://127.0.0.1:11434/v1`.
- Сохранять `Ollama Remote` как отдельную идентичность в конфигурации, сессиях и метриках; оба Ollama-провайдера работают без API-ключа.
- Добавить воспроизводимые проверки сетевого доступа, многошагового чата, нескольких последовательных запросов, rate limit и максимального контекста.
- Подготовить код развертывания, отчёт Дня 30 и сценарий короткого демонстрационного видео без нагрузочного тестирования и аппаратного мониторинга.

## Capabilities

### New Capabilities

- `private-llm-service`: Развертывание локальной модели на Raspberry Pi как приватного LAN-сервиса с HTTP-чатом, проверками устойчивости и явными ограничениями.

### Modified Capabilities

- `local-llm-provider`: Наряду с неизменным локальным `Ollama` появляется отдельный `Ollama Remote`, направляющий запросы на явно настроенный сервис Raspberry Pi.

## Impact

- Перечень провайдеров, конфигурация, отображение CLI и формирование URL в `src/config.rs`, `src/providers.rs`, `src/cli.rs`, `src/agent.rs` и связанных persistence-путях.
- Регрессионные тесты provider identity, конфигурации, сессий и локальных/удалённых Ollama-запросов в `src/tests.rs`.
- Версионируемые шаблоны конфигурации Ollama и HTTP gateway, а также скрипты установки и проверки; реальные сетевые адреса и секреты в Git не добавляются.
- Новый отчёт `reports/day30/` с командами воспроизведения, результатами проверок и сценарием видео.
- Raspberry Pi 5 с 64-битной ОС и активным охлаждением выступает сервером; MacBook используется только как сетевой клиент.
