## Purpose

Позволяет пользователю `fox-llm` подключить один MCP-сервер, увидеть объявленные им инструменты и явно выбрать инструменты, разрешённые для будущего использования агентом.

## ADDED Requirements

### Requirement: MCP configuration is backward-compatible
Система SHALL хранить конфигурацию единственного MCP-сервера в `.fox-llm.json` как необязательный адрес и список имён включённых инструментов. Конфигурация, созданная до появления MCP-секции, MUST продолжать загружаться без ручной миграции.

#### Scenario: Existing configuration has no MCP section
- **WHEN** `fox-llm` загружает корректный прежний `.fox-llm.json` без MCP-секции
- **THEN** приложение запускается с ненастроенным MCP-сервером и пустым списком включённых инструментов

#### Scenario: MCP selection survives restart
- **WHEN** пользователь сохранил проверенный адрес сервера и включил инструменты, а затем перезапустил `fox-llm`
- **THEN** приложение восстанавливает тот же адрес и список включённых инструментов

### Requirement: MCP menu reports connection state
Команда `/mcp` SHALL открывать интерактивное меню единственного MCP-сервера и проверять настроенный сервер посредством MCP handshake и запроса списка инструментов. Пользовательские сообщения и ошибки SHALL быть на русском языке.

#### Scenario: Configured server is available
- **WHEN** пользователь выполняет `/mcp`, а настроенный сервер успешно отвечает на MCP handshake и `tools/list`
- **THEN** меню показывает адрес доступного сервера и разрешает просмотреть или изменить выбор инструментов

#### Scenario: Server is not configured
- **WHEN** пользователь выполняет `/mcp` без сохранённого адреса сервера
- **THEN** меню сообщает, что сервер не настроен, и предлагает указать адрес либо отменить действие

#### Scenario: Configured server is unavailable
- **WHEN** пользователь выполняет `/mcp`, а сохранённый сервер не отвечает, отклоняет соединение или возвращает ошибку MCP
- **THEN** меню показывает понятную причину и предлагает повторить подключение, указать другой адрес либо выйти, не удаляя текущую конфигурацию

### Requirement: New server address is validated before persistence
Система MUST принимать только корректный HTTP(S)-адрес MCP endpoint и MUST успешно выполнить MCP handshake и `tools/list` до сохранения нового адреса. Смена сервера SHALL очищать ранее включённые инструменты.

#### Scenario: New address is reachable
- **WHEN** пользователь вводит корректный адрес совместимого MCP-сервера и проверка соединения завершается успешно
- **THEN** система сохраняет новый адрес, очищает старый список включённых инструментов и открывает меню подключённого сервера

#### Scenario: New address cannot be used
- **WHEN** пользователь вводит некорректный адрес либо сервер не проходит handshake или `tools/list`
- **THEN** система показывает ошибку и не заменяет ранее сохранённый адрес и выбор инструментов

### Requirement: User can inspect and select server tools
Система SHALL показывать полный актуальный список инструментов из `tools/list`, включая имя, описание при его наличии и состояние включения. Пользователь SHALL иметь возможность атомарно подтвердить новый набор включённых инструментов; новые инструменты SHALL быть выключены по умолчанию.

#### Scenario: Tools are listed
- **WHEN** подключённый сервер возвращает один или несколько инструментов
- **THEN** `/mcp` показывает каждый инструмент и отмечает его как включённый только при наличии его имени в сохранённом выборе

#### Scenario: User changes enabled tools
- **WHEN** пользователь отмечает или снимает отметки инструментов и подтверждает выбор
- **THEN** система сохраняет ровно выбранные имена доступных инструментов в `.fox-llm.json`

#### Scenario: User cancels tool selection
- **WHEN** пользователь покидает выбор инструментов без подтверждения
- **THEN** сохранённый список включённых инструментов не изменяется

#### Scenario: Previously enabled tool disappeared
- **WHEN** сервер больше не возвращает имя ранее включённого инструмента
- **THEN** меню продолжает работать, не показывает отсутствующий инструмент как доступный и исключает его при следующем подтверждённом сохранении выбора

### Requirement: Local demonstration server is independently runnable
Репозиторий SHALL предоставлять отдельный режим запуска локального MCP-сервера командой `cargo run -- --mcp-server`. Сервер MUST слушать только loopback-интерфейс, предоставлять инструмент `echo` и быть совместимым с клиентом `/mcp`.

#### Scenario: Demo server exposes echo
- **WHEN** локальный сервер запущен и клиент подключается к его MCP endpoint
- **THEN** MCP handshake завершается успешно, а `tools/list` содержит инструмент `echo` с описанием и входной схемой

#### Scenario: Echo receives text
- **WHEN** MCP-клиент вызывает `echo` с текстовым аргументом
- **THEN** сервер возвращает тот же текст как успешный результат инструмента
