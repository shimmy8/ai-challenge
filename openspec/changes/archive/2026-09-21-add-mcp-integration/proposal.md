## Why

`fox-llm` пока не умеет подключаться к MCP-серверам и обнаруживать предоставляемые ими инструменты. Для задания Дня 16 нужен минимальный, проверяемый сценарий: отдельный локальный MCP-сервер, подключение к нему из интерактивного CLI и управление доступностью найденных инструментов.

## What Changes

- Добавляется команда `/mcp` с интерактивным меню для проверки состояния единственного настроенного MCP-сервера, изменения его адреса и просмотра доступных инструментов.
- Адрес MCP-сервера и имена включённых инструментов сохраняются в локальном `.fox-llm.json`; существующая конфигурация без секции `mcp` продолжает загружаться.
- При открытии `/mcp` клиент устанавливает MCP-соединение и запрашивает `tools/list`. Если сервер не настроен или недоступен, CLI объясняет причину и предлагает указать новый адрес; новый адрес сохраняется только после успешной проверки.
- Пользователь может включать и выключать инструменты сервера. Новые инструменты по умолчанию выключены, исчезнувшие инструменты не мешают подключению и удаляются из сохранённого выбора при следующем успешном сохранении.
- Добавляется режим запуска локального MCP-сервера отдельной командой `cargo run -- --mcp-server` с простым инструментом `echo`, чтобы соединение и список инструментов можно было продемонстрировать без внешних сервисов.
- Добавляются регрессионные и интеграционные проверки конфигурации, MCP handshake, получения списка инструментов, ошибок подключения и сохранения выбора.
- В `reports/day16/` документируется запуск и короткий сценарий записи видео.
- Вызов MCP-инструментов моделью и поддержка нескольких серверов в эту итерацию не входят.

## Capabilities

### New Capabilities

- `mcp-tool-management`: Подключение к одному MCP-серверу, обнаружение его инструментов и управление локальным списком включённых инструментов через `/mcp`.

### Modified Capabilities

Нет. Интеграция MCP не изменяет требования существующих возможностей памяти, профилей, задач и инвариантов.

## Impact

- `Cargo.toml` и `Cargo.lock`: официальный Rust MCP SDK и зависимости транспорта/локального HTTP-сервера.
- `src/config.rs`: опциональная конфигурация единственного MCP-сервера и включённых инструментов с обратной совместимостью старых файлов.
- Новый модуль MCP: подключение по Streamable HTTP, handshake, `tools/list`, нормализация сохранённого выбора и локальная реализация `echo`.
- `src/app.rs`, `src/cli.rs` и `src/main.rs`: диспетчеризация `/mcp`, интерактивные меню, сообщения об ошибках и отдельный режим запуска локального сервера.
- `src/tests.rs`: модульные и асинхронные интеграционные тесты с изолированным сервером на временном локальном порту.
- `README.md` и `reports/day16/`: пользовательская инструкция и сценарий видео.
