## MODIFIED Requirements

### Requirement: Enabled MCP tools are available to every supported provider
Система SHALL передавать OpenAI и Claude актуальные определения только тех инструментов настроенного MCP-сервера, имена которых присутствуют в сохранённом allowlist, а при наличии хотя бы одного такого инструмента SHALL также передавать встроенное определение инструмента планирования пайплайна. MCP-инструменты и встроенный инструмент планирования SHALL быть доступны только основному модельному запросу и MUST NOT передаваться запросам сжатия, суммаризации или проверки инвариантов.

#### Scenario: Enabled tool is advertised
- **WHEN** настроенный MCP-сервер доступен и объявляет инструмент, имя которого включено пользователем
- **THEN** основной запрос выбранному провайдеру содержит имя, описание и входную схему этого инструмента

#### Scenario: Pipeline planner is advertised
- **WHEN** основной запрос получает хотя бы один разрешённый MCP-инструмент
- **THEN** он также получает встроенный структурированный инструмент планирования пайплайна

#### Scenario: Disabled tool is hidden
- **WHEN** MCP-сервер объявляет инструмент, отсутствующий в сохранённом allowlist
- **THEN** система не передаёт его определение модели и не разрешает его выполнение напрямую или как шага пайплайна

#### Scenario: Auxiliary request does not receive tools
- **WHEN** агент выполняет суммаризацию, сжатие контекста или проверку инвариантов
- **THEN** запрос не содержит определений MCP-инструментов или инструмента планирования независимо от allowlist

### Requirement: Tool execution is constrained and fail-closed
Перед каждым прямым вызовом и шагом пайплайна система MUST повторно проверять имя по снимку актуального списка инструментов и allowlist и MUST считать ошибку MCP результатом инструмента, а не успешным внешним действием. Система MUST ограничивать один пользовательский запрос тремя top-level structured tool calls модели; один принятый вызов планирования считается одним top-level call и MAY выполнить не более восьми последовательных MCP-шагов. Модель MUST NOT получать секреты MCP-сервера, GitHub или CalDAV.

#### Scenario: Model requests a disabled tool
- **WHEN** модель напрямую или внутри плана запрашивает отсутствующий, исчезнувший или выключенный инструмент
- **THEN** система не выполняет вызов и возвращает структурированную ошибку о недоступности инструмента

#### Scenario: Tool call limit is reached
- **WHEN** модель пытается выполнить более трёх прямых или планирующих structured tool calls в рамках одного пользовательского запроса
- **THEN** система прекращает цикл без четвёртого top-level вызова и сообщает пользователю о превышении лимита

#### Scenario: Pipeline step limit is reached
- **WHEN** один план содержит более восьми MCP-шагов
- **THEN** система отклоняет план до выполнения первого шага и сообщает пользователю о превышении лимита

#### Scenario: MCP call fails
- **WHEN** прямой инструмент или шаг пайплайна возвращает ошибку, соединение прерывается или истекает тайм-аут
- **THEN** система не заявляет об успешном действии и передаёт модели безопасное описание ошибки без учётных данных
