# Raspberry Pi 5: приватный Ollama-сервис

Каталог разворачивает `qwen3:1.7b` на ARM64 Raspberry Pi 5 с 8 ГБ RAM. Ollama
слушает только `127.0.0.1:11434`; в локальную сеть выходят `/api/` и `/v1/`
через Nginx на порту `11435`.

## Однократная установка

Нужны 64-битная Raspberry Pi OS/Debian, активное охлаждение и фиксированный
IPv4. Скопируйте этот каталог на Pi и выполните одну команду, подставив адрес Pi
и CIDR своей локальной сети:

```bash
sudo ./setup.sh --listen-address <PI_FIXED_IP> --lan-cidr <LAN_CIDR>
```

`setup.sh` сам устанавливает Nginx, curl и официальную ARM64-сборку Ollama,
проверяет принадлежность адреса Pi, сохраняет заменяемые файлы в
`/var/backups/fox-llm-day30/<timestamp>`, загружает `qwen3:1.7b`, создаёт alias
`fox-qwen-pi`, настраивает `num_ctx=4096`, одну параллельную генерацию и одну
загруженную модель. В конце он проверяет Nginx и запускает сервис.

Если базовая модель заранее перенесена на Pi без registry, повторную загрузку
можно пропустить. Скрипт сначала проверит локальное наличие модели и только
после этого создаст deployment alias:

```bash
sudo ./setup.sh --listen-address <PI_FIXED_IP> --lan-cidr <LAN_CIDR> --skip-pull
```

## Последующие запуски и перезапуски

После перезагрузки Pi или для ручного перезапуска нужна только команда:

```bash
sudo ./start.sh
```

Скрипт ждёт готовности Ollama, проверяет наличие `fox-qwen-pi`, выполняет
`nginx -t` и перезапускает gateway. Параметры адреса повторно указывать не нужно.
Оба сервиса также включены в автозапуск операционной системы.

Rate limit gateway: `30` запросов в минуту с burst `5` на один IP. Превышение
возвращает `429`. `client_max_body_size=256k` — отдельный транспортный лимит, а
не размер контекста модели. Streaming не буферизуется.

## Обновление и откат

После обновления Ollama или файлов каталога повторно запустите `setup.sh` с
теми же параметрами. Каждая установка создаёт новый backup. Для отката укажите
выведенный скриптом точный каталог:

```bash
sudo ./rollback.sh /var/backups/fox-llm-day30/<timestamp>
```

Проверка границы сети с MacBook:

```bash
curl --fail http://<PI_FIXED_IP>:11435/api/tags
curl --connect-timeout 2 http://<PI_FIXED_IP>:11434/api/tags
```

Первый запрос должен пройти, второй — завершиться ошибкой соединения. Полный
набор учебных проверок запускается по инструкции в `reports/day30/README.md`.
