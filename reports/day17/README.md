# День 17 — MCP-инструмент Яндекс Календаря

## Что реализовано

`fox-llm` получает определения инструментов через MCP `tools/list`, передаёт
их выбранному провайдеру нативным tool-calling и после подтверждения вызывает
`create_calendar_event`. Инструмент использует CalDAV Яндекс Календаря и не
выводит учётные данные в ошибки или результаты.

Схема входа:

```json
{
  "title": "Встреча с Анной",
  "start_at": "2026-09-23T15:00:00+03:00",
  "end_at": "2026-09-23T16:00:00+03:00",
  "description": "Обсудить проект",
  "location": "Онлайн"
}
```

Результат содержит безопасное резюме: `event_id`, `title`, `start_at`,
`end_at` и имя календаря. До записи проверяются RFC 3339 со смещением и
условие `end_at > start_at`.

## Демонстрация

Пароль создаётся в разделе [Пароли приложений Яндекс ID](https://www.yandex.ru/support/id/ru/authorization/app-passwords), тип «Календарь». CalDAV-адрес Яндекса — `https://caldav.yandex.ru`; подробная официальная инструкция находится в [документации синхронизации календаря](https://yandex.ru/support/yandex-360/customers/calendar/web/ru/data-exchange/synchronization/sync-desktop).

Терминал 1 — подготовьте локальный файл и запустите MCP-сервер:

```bash
cp .env-mcp.example .env-mcp
# отредактируйте .env-mcp; MCP-сервер прочитает его сам
cargo run -- --mcp-server
```

Терминал 2 — клиент:

```bash
cargo run
```

В клиенте выполните `/mcp`, включите `create_calendar_event`, затем скажите:
«Запланируй встречу с Анной завтра в 15:00 на час». Ожидаемый preview:
название, начало и окончание события; ответьте `да`. После результата проверьте
событие в личном Яндекс Календаре и удалите тестовую запись вручную.

## Результат ручной проверки

Сценарий успешно проверен: агент сформировал абсолютный интервал в
`Europe/Moscow`, показал preview, получил подтверждение пользователя и создал
ровно одно событие в выбранном личном календаре Яндекса. Событие было видно в
веб-интерфейсе календаря; тестовая запись удалена вручную. Секреты и личные
данные в отчёт не записывались.

Видео: показать выключенный allowlist, `/mcp`, фразу пользователя, preview,
подтверждение и одно появившееся событие в календаре (без показа пароля).

## Проверки

Локально без сетевого доступа к CalDAV выполнены:

```bash
cargo fmt --all -- --check
cargo clippy --offline --all-targets --all-features -- -D warnings
cargo test --offline -- --skip demo_server_supports_handshake_tool_listing_and_echo
openspec validate add-yandex-calendar-mcp-tool --strict
```

Полный MCP-тест с ephemeral loopback-сервером в текущем sandbox не запускается:
операционная система запрещает `TcpListener::bind`. Ручная проверка с личным
календарём выполнена успешно; локальные реквизиты в отчёт не включались.
