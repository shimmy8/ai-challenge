# Аудит команд файлового ассистента

Снимок предназначен для воспроизводимого сценария создания и повторного no-op.

| Команда | Назначение | Изменяет файлы |
| --- | --- | --- |
| `/project <цель>` | Запускает изолированный goal-oriented workflow | Только после preview и подтверждения |
| `/help <вопрос>` | Отвечает по проектной документации и CodeGraph | Нет |
| `/mcp` | Управляет пользовательским MCP-реестром | Нет файлов проекта |

Project-only runtime предоставляет `list_files`, `search_files`, `read_file`,
`write_file`, `git_diff` и `codegraph_explore`. Единственный write-tool требует
evidence текущего запуска и повторно проверяет hash либо отсутствие цели.
