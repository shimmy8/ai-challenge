# День 16 — подключение MCP

## Результат

`fox-llm` подключается к одному MCP-серверу по Streamable HTTP через официальный
Rust SDK `rmcp`. Команда `/mcp` проверяет handshake и `tools/list`, показывает
инструменты и сохраняет включённый allowlist в `.fox-llm.json`.

В репозитории есть локальный демонстрационный сервер с инструментом `echo`.
Вызов MCP-инструментов моделью пока не выполняется — это граница текущего дня.

## Демонстрация в двух терминалах

В первом терминале:

```bash
cargo run -- --mcp-server
```

Ожидается:

```text
MCP-сервер запущен: http://127.0.0.1:8000/mcp
```

Во втором терминале запустите обычный клиент и выполните `/mcp`. Если локальный
`.fox-llm.json` ещё не настроен для обычного запуска, завершите первичную
настройку провайдера; MCP не отправляет запросов к LLM.

В меню выберите адрес `http://127.0.0.1:8000/mcp`, затем откройте список
инструментов. В списке должен быть:

```text
echo — Возвращает переданный текст без изменений
```

Поставьте отметку на `echo`, подтвердите выбор, снова откройте `/mcp` и покажите,
что отметка сохранилась. После остановки сервера повторите `/mcp`: CLI должен
сообщить о недоступности и предложить повторить подключение или указать новый
адрес, сохранив текущую конфигурацию до успешной проверки.

## Shot list для видео

1. Запуск `cargo run -- --mcp-server` и адрес endpoint.
2. Выполнение `/mcp` в обычном `fox-llm`.
3. Успешный статус сервера и найденный `echo`.
4. Включение `echo` через интерактивный список.
5. Повторное открытие `/mcp` с сохранённой отметкой.
6. Остановка сервера и сообщение о недоступности.

## Проверки

```bash
cargo test --offline config
cargo test --offline mcp
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
```

Интеграционный тест поднимает MCP-сервис на автоматически выбранном loopback-порту,
проверяет handshake, `tools/list` и вызов `echo` без внешнего LLM API.
