# FAQ службы поддержки

## Почему после установки я не могу войти?

Образ не создаёт первого пользователя автоматически. Создайте суперпользователя
внутри контейнера. Если прямой вход работает, а через reverse proxy — нет,
проверьте forwarding заголовков и trusted origins.

## Почему REST API отвечает 401?

REST API принимает token из Settings, а не пароль от веб-интерфейса. Передавайте
его в заголовке `Authorization` со схемой `Token`. Не прикладывайте реальный token
к тикету.

## Почему пропали данные после пересоздания контейнера?

Каталог `/etc/linkding/data` должен быть примонтирован к постоянному каталогу
хоста. Без volume данные принадлежат удалённому контейнеру. Восстановите backup и
перезапустите контейнер с правильным mount.

## Почему экспорт не восстановил снимки страниц?

Netscape HTML переносит закладки, но не HTML snapshots и другие assets. Для
полного восстановления нужны база и каталог assets из data-каталога.

## Почему автоматический снимок не создаётся?

Серверные снимки доступны в образе `latest-plus`. Для браузерного варианта
проверьте endpoint SingleFile, token и установку обоих расширений из одного
магазина. Для существующей закладки SingleFile запускают вручную.

## Архивирование удаляет закладку?

Нет. Архивная закладка остаётся в базе и может быть возвращена через unarchive.
Удаление — отдельная операция.
