# Расширение браузера

Официальное расширение linkding доступно для Firefox и браузеров на Chromium.
Оно позволяет добавлять текущую страницу и искать сохранённые закладки из
адресной строки. В настройках расширения укажите URL своего экземпляра и данные
доступа, не отправляя token третьим лицам.

Для снимков расширение linkding умеет запускать SingleFile после создания новой
закладки. Сначала настройте SingleFile на upload в REST endpoint linkding, затем
включите соответствующую опцию в расширении linkding. Оба расширения должны быть
установлены из одного магазина: их идентификаторы зависят от магазина. Интеграция
не запускается при обновлении уже существующей закладки; тогда снимок создают
кнопкой SingleFile вручную.

Источники: <https://linkding.link/browser-extension/> и
<https://linkding.link/archiving/>.
