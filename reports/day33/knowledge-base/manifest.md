# Корпус поддержки linkding

Локальный учебный snapshot подготовлен 15 октября 2026 года по официальной
документации linkding версии `v1.47.0`, commit `24b5ad6`.

- upstream: <https://github.com/sissbruecker/linkding>
- документация: <https://linkding.link/>
- release: <https://github.com/sissbruecker/linkding/releases/tag/v1.47.0>
- лицензия upstream: MIT, <https://github.com/sissbruecker/linkding/blob/v1.47.0/LICENSE>

Файлы в этом каталоге — краткий русскоязычный пересказ выбранных публичных
страниц, а не полная копия upstream. `faq.md` написан специально для учебного
ассистента. Корпус намеренно содержит только Markdown и не включает настройки,
ключи, базы данных, логи или сгенерированные embeddings.

## Карта источников

- `getting-started.md` — Installation;
- `authentication.md` — Installation, API и Troubleshooting;
- `browser-extension.md` — Browser Extension и Archiving;
- `import-export.md` — Backups;
- `archiving.md` — Archiving;
- `faq.md` — проектный FAQ на основе перечисленных страниц.
