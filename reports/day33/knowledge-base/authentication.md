# Авторизация и API token

В веб-интерфейс входят с именем пользователя и паролем, созданными для экземпляра
linkding. Для REST API используется отдельный token пользователя из Settings.
Клиент передаёт его в HTTP-заголовке `Authorization` со схемой `Token`.

Не вставляйте API token в URL и не публикуйте его в тикете. При `401` сначала
проверьте, что используется именно token из настроек нужного пользователя, схема
заголовка написана правильно и запрос приходит в тот экземпляр linkding.

Ошибки формы входа за reverse proxy часто связаны не с паролем, а с неверными
`Host` / `X-Forwarded-Proto` или CSRF trusted origins. Для диагностики сравните
прямой локальный вход и вход через proxy, затем исправьте proxy-настройки.

Источники: <https://linkding.link/api/> и
<https://linkding.link/troubleshooting/>.
