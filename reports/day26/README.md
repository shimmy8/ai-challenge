# День 26. Локальная LLM в `fox-llm`

## Окружение

- MacBook Pro на Apple M1, 16 ГБ unified memory;
- Ollama `0.35.1`;
- локальная модель `qwen3.5:4b`, размер на диске 3.3 ГБ;
- локальный API `http://127.0.0.1:11434`;
- провайдер `Ollama` внутри `fox-llm` без API-ключа.

Проверка установки:

```bash
ollama --version
ollama list
curl http://127.0.0.1:11434/api/version
```

Наблюдаемый результат: сервер вернул версию `0.35.1`, а `ollama list` показал
`qwen3.5:4b` размером 3.3 ГБ.

## Проверка прямого HTTP API

```bash
curl http://127.0.0.1:11434/v1/responses \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen3.5:4b",
    "input": "Ответь одним коротким предложением: что такое локальная LLM?",
    "temperature": 0.2,
    "reasoning": {"effort": "none"}
  }'
```

Responses API вернул `status: completed`, текстовый `output` и `usage`. Ответ
определил локальную LLM как языковую модель, работающую на устройстве без
отправки данных в облако.

## Запуск через проект

```bash
cargo run
```

При первом запуске выбран `Ollama`. CLI не запросил API-ключ, показал модель
`qwen3.5:4b` в статус-баре и отправил запросы через локальный `/v1/responses`.

### Три запроса разной сложности

| Уровень | Запрос | Наблюдаемый результат | Время | Токены запроса/ответа |
|---|---|---|---:|---:|
| Простой | «Ответь одним предложением: что такое локальная LLM?» | Одно определение локальной LLM | 4.381 с | 113 / 49 |
| Средний | «Составь краткий план изучения Rust на 7 дней: по одной практической задаче на каждый день» | План из семи практических заданий | 18.207 с | 194 / 309 |
| Сложный | «Напиши `word_frequencies` на Rust, игнорируя регистр и пунктуацию, и объясни сложность» | Код с `HashMap<String, usize>` и оценка `O(N)` | 34.983 с | 558 / 568 |

Ответ на кодовый запрос демонстрирует генерацию кода локальной моделью, но, как
и любой сгенерированный код, требует проверки компилятором перед использованием.
