# fox-llm

Интерактивный CLI-клиент на Rust для общения с OpenAI и Claude.

## Запуск

```bash
cargo run
```

При первом запуске CLI предложит выбрать провайдера, а затем способ добавления
ключа: открыть официальную страницу для создания нового или ввести уже
существующий. Каждый введённый символ ключа отображается звёздочкой, поэтому
длина ввода видна, но сам ключ остаётся скрытым. Настройки сохраняются в
`.fox-llm.json` в текущей директории. Файл исключён из Git и на Unix получает
права `0600`.

## Команды

- `/provider` — сменить провайдера;
- `/mode` — выбрать режим ответа или создать новый;
- `/new` — очистить историю и начать новую сессию;
- `/quit` — выйти;
- `/help` — показать подсказку.

Начните ввод с `/`: CLI покажет продолжение команды. Нажмите `Tab`, чтобы
подставить команду или увидеть все подходящие варианты. Невведённая часть
подсказки отображается приглушённым цветом; `Enter` сразу выполняет показанную
команду.

## Режимы ответа

Команда `/mode` открывает список сохранённых режимов. В нём всегда доступен
режим «Без ограничений» и пункт создания нового режима. Пользовательский режим
содержит название и инструкции. Формат, длина и условие завершения ответа
задаются непосредственно в тексте этих инструкций.

Инструкции вводятся в многострочном режиме: вставьте промпт целиком, затем
введите `/done` на отдельной строке. Если режим с таким названием уже есть, CLI
предложит заменить его.

Режимы и последний выбранный режим сохраняются в `.fox-llm.json`. При смене
режима история диалога очищается, чтобы новые инструкции не смешивались с
предыдущей сессией.

Провайдеры хранятся списком. Модели и ключи можно изменить в `.fox-llm.json`:

```json
{
  "last_provider": "openai",
  "last_mode": "Краткий ответ",
  "modes": [
    {
      "name": "Краткий ответ",
      "instructions": "Ответь тремя пунктами. Используй не более 1000 символов. Заверши отдельной строкой <END>."
    }
  ],
  "providers": [
    {
      "provider": "openai",
      "api_key": "sk-...",
      "model": "gpt-5-mini"
    },
    {
      "provider": "claude",
      "api_key": "sk-ant-...",
      "model": "claude-sonnet-5"
    }
  ]
}
```

Старый формат конфигурации автоматически преобразуется при запуске.

API-ключи являются секретами. Не коммитьте и не отправляйте этот файл другим людям.
